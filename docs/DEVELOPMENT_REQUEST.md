# 원작자 구현 요청서

## 전달하고 싶은 핵심

> 지역은 출발점이고, 학교·지원·이주·진로에 관한 선택은 가족의 하루와 다음 배움길을 바꾼다. 한 아이의 삶을 경험한 뒤 실제 학령인구 자료를 보며 필요한 교육적 연결을 생각한다.

이 저장소는 원하는 화면과 경험을 직접 체험할 수 있게 만든 참고 구현입니다. 기존 「경북의 아이」 원작의 장점인 자동으로 흐르는 인생 기록과 중요한 순간의 결정을 살리면서 아래 방향으로 발전시켜 주세요. 현재 코드를 그대로 채택하거나 원작 구조에 옮길지는 편한 방식을 선택하셔도 됩니다.

## 경험의 흐름

1. 경북 지역을 고르면 가상 이름·생활 배경·지역 위치와 함께 시작합니다.
2. 일상 이야기는 자동으로 흐르고, 중요한 결정에서는 기다립니다.
3. 어린이집·유치원, 초등학교, 지원, 생활권·이주, 중학교, 배움의 연결, 고등학교, 졸업 후 경로, 첫 진로를 고릅니다.
4. 선택 직후 통학·가족 일정·비용·관계·다음 기회가 어떻게 달라졌는지 보여 줍니다.
5. 이전 선택과 지역에 따라 다음 질문과 후보가 바뀌고, 스무 살 이후는 빠르게 흐릅니다.
6. 다양한 행복한 결말과 인생 여권으로 돌아본 뒤 학령인구 대시보드로 이어집니다.

## 특히 살려 주세요

| 부분 | 원하는 구현 |
|---|---|
| 인생의 선택 | 비슷한 활동 과제나 설문 대신 학교·거주·지원·진학·일·예체능·기술 등 삶의 방향을 바꾸는 결정 |
| 지역성 | 실제 지역의 생활 여건·기관·학교·교육적 연결이 사건과 선택에 드러나기. 지역을 바꿔도 이름만 달라지는 구성 피하기 |
| 후속 분기 | 예술 지원을 고르면 작품·예술 경로와 제작 기술로의 전환이 열리고, 원격 연결을 고르면 이주 없이 배움을 이어 가는 등 이전 선택을 기억하기 |

| 존중 | 지역·학교 규모·가정 형태로 사람의 능력이나 미래를 단정하지 않기. 다른 진로와 재시작도 존중받는 결말 |
| 조작 | 자동 진행·멈춤·다음 장면·장면 머무는 시간 조절. x1/x2/x4 대신 초 단위 속도. 효과음 없이 읽고 선택하기 |

## 시간과 자료

- 2008년 출생 → 2026년 열여덟. 나이는 이야기 연도에서 출생연도를 뺀 값입니다.
- 2027년 이후는 상상하는 미래입니다. 현재 정책의 미래 수혜를 보장하지 않습니다.
- 기관·학교 수치는 공시 연도를 붙이고, 과거에 확인되지 않은 수치는 미확인으로 표시합니다. 현재 원아 수를 과거 원아 수처럼 쓰지 않습니다.
- 농어촌 전형은 출생지만으로 적용하지 않습니다. 대학별 재학·거주·제외 학교 조건을 확인하는 상담 경로로 표현합니다.
- 진학 후보는 가상의 희망 경로입니다. 실제 학구·성별 모집·실기·지원 자격을 보장하지 않습니다.

## 디자인과 캐릭터

알지 공식 이미지의 노랑·파랑·짙은 파랑과 밝은 바탕을 중심으로, 부드러운 삽화와 정돈된 카드·큰 선택 버튼을 사용해 주세요. 흔들리거나 과도한 모션보다 장면 전환·선택 결과·성장 변화가 자연스럽게 이어지는 움직임을 원합니다. 움직임 줄이기도 유지해 주세요.

알지 머리띠의 이름은 현재 **마호니**이며 `public/config.js`의 `creatorName`에서 바꿉니다. 추후 제작자 표기는 박하은 선생님으로 변경할 예정입니다. 화면의 기관·대시보드 링크에는 교사 실명을 넣지 않고 **학령인구 대시보드**라고 안내합니다. 브랜드 공식 명칭은 **GBE-AI Lab**입니다.

## 비교하며 확인할 세 경로

- 같은 지역에서 학습 지원 → 원격 연결 → 진학과, 예술 지원 → 제작 기술 연결 → 일과 후학습을 비교합니다.
- 울릉처럼 이동 여건이 다른 지역에서 현재 생활권 유지와 다른 지역 이주를 비교합니다.
- 같은 출발에서 스무 살의 진로를 바꿨을 때 성인기 이야기와 결말이 실제로 달라지는지 확인합니다.

각 경로에서 다음 선택 후보, 현재 지역·학교, 가족 생활 변화, 최종 결말 중 무엇이 바뀌었는지 보여 주면 좋겠습니다. 설명만 길어지는 부분은 짧은 사건·대화로 다듬어 주세요.

## 구현 시 유지할 조건

HTML/CSS/JavaScript로 구성하고 실제 학생 개인정보를 받지 않습니다. API 키는 프런트엔드나 저장소에 넣지 않습니다. 저장 형식이나 선택 ID를 바꾸면 이전 기록 복원 또는 명시적인 이관을 함께 설계합니다. `legacy-*` 파일은 기존 진행 복원에 쓰이므로 임의로 삭제하지 않습니다.

추가할 장편 이야기나 애니메이션보다 먼저, 선택에 따른 후속 변화·중복 없는 일상·시대와 지역에 맞는 사건이 안정적으로 작동하면 좋겠습니다.
