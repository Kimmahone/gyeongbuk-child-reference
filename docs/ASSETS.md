# 캐릭터·이미지·폰트

- **알지**: 사용자 제공 캐릭터를 바탕으로 구성했습니다. `public/assets/algi-original.png`는 원본 참고, `algi-blank-band.png`는 제작자 이름을 겹쳐 표시하는 머리띠용 이미지입니다.
- **이름**: 현재 마호니. `public/config.js`의 `creatorName`과 화면·인쇄용 오버레이로 표시합니다. 브랜드는 GBE-AI Lab / TEAM LEAP입니다.
- **성장·배경**: `child-life-v050.png`, `life-worlds.png`는 창작 삽화이며 실제 학교나 지역의 사진이 아닙니다.
- **폰트**: Noto Sans KR, Inter를 로컬 파일로 제공합니다. 각 폴더의 `OFL.txt`를 유지하세요.
- **지도**: OpenStreetMap 출처·ODbL 표시를 유지합니다.
- **QR**: 현재 운영 게임과 대시보드의 공개 주소입니다. 개인 결과를 담지 않습니다. 새 배포 주소로 운영하려면 이미지·메타데이터·화면 링크를 함께 갱신해야 합니다.

이 전달본은 전체 코드와 캐릭터에 새로운 오픈소스 라이선스를 임의로 부여하지 않습니다. 사용자 제공 캐릭터와 자료의 기존 출처·이용 조건은 유지합니다.
