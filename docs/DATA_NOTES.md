# 자료 범위와 시점

기준: 2026-11-08 / 참고 코드 1.0.0-rc.1.

| 자료 | 연결 범위 | 구분해야 할 점 |
|---|---|---|
| 어린이집 | 공식 포털 2026-10-31 내려받은 기본정보 1,128개. 정상 운영 1,049개가 현재 후보 기준 | 과거 운영·입소 가능 여부·당시 원아 수를 증명하지 않음 |
| 유치원 | 유치원알리미 API 607개. 2026년 2차 및 원아 수 조건을 만족한 497개가 현재 후보 기준 | 기관별 공시 차수, 일반·혼합·특수 합산. 결측은 0으로 바꾸지 않음 |
| 학교 | NEIS의 유효 코드가 있는 초·중·고 915개 | 현재 명칭·학교 유형. 과거 교명·학과·배정 가능 여부 전수 확인 아님 |
| 학생·학급 수 | TEAM LEAP 2026-09-11 공개 가공 보관본의 2026 공시와 연결 가능한 2016~2025 기록 | 원시 공시 실시간 재조회가 아니며 집계 기준이 다른 숫자를 한 시계열로 합치지 않음 |
| 정책 | 공식 교육청·교육부·법령·대학 모집요강에 연결 | 발표/갱신 연도와 적용/실적 연도 구분. 지원 자동 수혜·입학 보장 아님 |
| 지도 | 공개 지리 자료를 바탕으로 한 대략적 위치 | 실제 통학 거리·시간 계산이 아님. 울릉 별도 표시 |

공식 출처 링크와 개별 시점은 데이터 파일의 `meta` 및 `policy-review.js`, 앱의 ‘이야기와 자료’에서 확인할 수 있습니다.
